# Services: a cache and webhooks

The guide to the optional services, a Valkey cache every instance shares and
webhooks for a command's effects, is on the site:
[Services](../site/src/content/docs/docs/services.md), published at
<https://mistriwork.dev/docs/services/>. A search engine is no longer one of
them: search providers are packs (`packs/search-typesense`), which ship after
1.0.

This file stays so the links that name it, the 0.4.0 changelog's among them,
still arrive somewhere.
